    Autohub

    Not yet reviewed. This page was imported from help.hubzero.org and has not been checked against Hubzero 2.4. It was last edited there in 2025. It was never published there, so read it as a draft. It exists only in the 2.2 documentation and was merged in from there.

    Spinning up a hub just got easier. Autohub is a script that streamlines the setup of a HUBzero development instance, changing a complex process into a few quick and easy steps.

    After running the script, you will be running a fully functional hub that offers the standard CMS features as well as virtualized Workspaces and, optionally, Solr search. This hub will allow you to safely experiment with a wide range of features as well as develop custom code. Autohub also lays the groundwork for remote PHP debugging, making it much easier to troubleshoot problems and fix software bugs.

    The hub instance that Autohub provides runs in a virtual machine (VM) on your computer, and requires some free software to get started (VirtualBox and Vagrant). See the Autohub README for more information.
