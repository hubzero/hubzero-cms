    Video tutorials

    There are no video tutorials in this repository, and none that this documentation can point you at.

    The page this replaces held a single link, to slides for a 2017 presentation called Contributing to the Hubzero CMS via GitHub: Feature Branch Demonstration, published as resource 1585 on help.hubzero.org. That is the site these pages replace, and nothing in this repository mirrors the slides or keeps them current. Follow the link only as an archive.

    What the presentation covered is written down here instead:

    • Contributing — forking, branching from a release line, and opening a pull request.
    • Commit messages — how a commit is written.
    • Development environment — getting a hub running to develop against.
