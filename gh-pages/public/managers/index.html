    Hub managers

    The administrator's guide. A hub manager configures the hub, manages its members and their access, curates its content, installs and configures extensions, and keeps the site healthy. Almost all of that happens in the administrator interface at /administrator, which this book walks through screen by screen.

    Where to start

    If the hub is new, read Getting started and then Configuring. They cover the first login, the global configuration, and the choices that are hard to change later.

    If you are taking over a running hub, start with Daily maintenance and Users.

    In this book

    • Getting started — the administrator interface and the first configuration.
    • Integrations — connecting the hub to analytics, Google Drive, the rich text editor, and CAPTCHA.
    • Daily maintenance — approving content, support tickets, cron jobs, notices, and tools.
    • Frequently asked questions
    • Configuring — hub settings, components, modules, plugins, registration, and authentication.
    • Users — members, access groups and levels, groups and super groups, member import, and user notes.
    • Menus
    • Content — articles and URLs.
    • Components — one chapter per component's administrative side, from Answers to Wishlist.
    • Extensions — the extension, module, template, and plugin managers.
    • Spam — the spam filters and how to tune them.
    • Security — hardening the operating system and the CMS.

    Every parameter you can set is also listed in the generated configuration reference.
