    Configuring

    Almost everything about a hub is set from the administrator interface. This section covers the four places settings live: the global configuration that applies to the whole site, the options attached to each component, the parameters on each module instance, and the parameters on each plugin.

    Where settings live

    Setting Where you edit it
    Site-wide settings — site name, mail, sessions, caching, SEO, permissions Site > Global Configuration. See Global configuration.
    One component's options The Options button in that component's toolbar. See Components.
    One module instance's parameters Extensions > Module Manager, then the module. See Modules.
    One plugin's parameters Extensions > Plug-in Manager, then the plugin. See Plugins.
    Which fields a new member must fill in Users > Members > Registration. See Registration.
    How people sign in Extensions > Plug-in Manager, filtered to the authentication type. See Authentication and External authenticators.
