    Getting started

    Getting started

    Draft. This page is still being written.

    Hubzero is an open source platform for building websites that support scientific discovery, learning, and collaboration. A site built on it is a hub: a place where a community publishes resources, runs simulation tools in the browser, works together in groups and projects, and talks in forums, wikis, and question-and-answer boards.

    This book is the short orientation. It explains the ideas the rest of the documentation takes for granted and points you to the book you need.

    Which book do you need?
