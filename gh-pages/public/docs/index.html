    Hubzero Documentation

    All books

    Documentation for Hubzero 2.4, the open source platform for scientific collaboration websites. It is organized as books, each for a different kind of reader. Everything here is Markdown in the hubzero-cms repository and is published at https://hubzero.github.io/hubzero-cms/.

    Start here

    • Getting started — what a hub is and the vocabulary the rest of the documentation uses.

    Run a hub

    • Installation — being rewritten for the new web installer.
    • Hub managers — administering a hub: configuration, users and access, content, extensions, maintenance, and every component's administrative side.

    Use a hub

    • Hub users — profiles, groups, projects, publications, resources, the wiki, forums, courses, and the other features a hub offers.
    • Tools — the tool platform: publishing simulation tools, invoke scripts, the submit command, Jupyter, and tool administration.

    Build on Hubzero

    • Developers — extending the CMS: the framework foundation, components, plugins, modules, templates, the database layer, and the REST API.
    • Contributing — coding conventions, commit practice, testing, and how to send changes back to the project.

    Reference

    • Reference — generated references: configuration parameters, REST endpoints, muse console commands, and events.
    • Releases — how Hubzero is released and where upgrade guidance lives.

    About the documentation

    • Writing guide — how pages are written and built.
    • License — MIT, like the code.
    • Status — which pages have been reviewed against the current code.

    Most of this material was imported from help.hubzero.org in September 2026 and is being reviewed against the code book by book. A page that has not yet been reviewed says so at the top.
