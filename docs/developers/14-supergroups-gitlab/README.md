# Super Groups & Gitlab

## What is Gitlab

In efforts to make super group development easier, we are utilizing a code management tool called [Gitlab](https://www.gitlab.com/). Similar to [Github](https://www.github.com/) in functionality and looks, it provides an easy way for the developers to write & push code and give the HUBzero team the security we needed to allow third party developers to commit code to production machines.
