# Environment

## The Tool Session

Tools sessions on hubs run in a container. Each tool session runs in the environment of the user who started the tool. Because it is in a container, you will not be able to see or interact with other users.

If you have workspace or ssh access, you can open a terminal and look around...

```
mmh@HUBzero:~$ w
 14:36:37 up 3 days, 22 min,  0 users,  load average: 0.00, 0.00, 0.00
USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU WHAT

mmh@HUBzero:~$ ps
  PID TTY          TIME CMD
 2113 pts/0    00:00:00 bash
 2201 pts/0    00:00:00 ps

mmh@HUBzero:~$ pwd
/home/hubzero/mmh

mmh@HUBzero:~$ echo $SESSION
19245

mmh@HUBzero:~$ echo $SESSIONDIR
/home/hubzero/mmh/data/sessions/19245
```

## Environment Variables

A number of environment variables are available in a tool session. A few are discussed here. A full list can be viewed by running the "env" command from a terminal in the workspace tool.

\*Note: tools are invoked by the user's account and permissions set accordingly. A tool can save files to a user's home directory because the tool runs as that user.

## SESSION="session id"

This variable stores the session ID or session number that is currently active. It's the ID of the session you are currently using.

## SESSIONDIR=/home/"hub hostname"/"username"/data/sessions/"session id"

This variable stores the current session directory of the open tool. This session directory is a separate directory created for each new tool session. It is readable and writable by the tool and the user. This is a good place for temporary files generated by your tool. Ideally, these temporary files should be removed when the tool no longer need them. Users will be prompted to remove these directories when they get low on disk space.

\*This is the default path for a Rappture tool on invoke.

## RESULTSDIR=/home/"hub hostname"/"username/data/results/"session id"

This variable stores the results directory located in the user's home directory. This is a good place to place simulation results for the user to access later. This is the default directory for Jupyter tools. Rappture xml output files are automatically placed here.

\*Be mindful of the user's quota limits. Users will be prompted to remove these directories when they get low on disk space.

## USER="username"

This variable stores the current username of the user running the tool.

## PWD=/"present working directory"

This variable stores the present working directory.

## HOME=/home/"hub hostname"/"username"

This variable stores the path of the user's home directory. This is useful if a tool provided an option to save the user's current work. Please create a directory for the tool to save files here, to prevent cluttering the user's home directory too much. A best practice would be to create a new directory for a tool in the user's data directory. For example, "$HOME/data/toolname".
