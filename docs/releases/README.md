# Releases

Release notes and upgrade guidance for Hubzero 2.4.

Hubzero is released from the `2.4-main` branch of the
[hubzero-cms repository](https://github.com/hubzero/hubzero-cms). Upgrade
steps for a running hub are being rewritten alongside the new web
installer; see [Installation](../installation/README.md).
