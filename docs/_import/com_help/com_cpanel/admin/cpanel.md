# Control Panel

The control panel is meant to give administrators an overview of activity and content on their site as well as provide shortcuts into common admin/maintenance functions. The panel is comprised entirely of modules. These modules can be set, rearranged, and modified via the Module Manager found under the "Extensions" menu item.
