# Menu Manager: Edit Menu Item

## How To Access

To create a new Single Article Menu Item:

- Select **Menus → [name of the menu]** from the drop-down menu on the back-end of your installation (for example, **Menus → Main Menu**).
- Click **New** to create a new menu item.
- Click the Menu Item Type Select button and then click the Single Article link under Articles.

To edit an existing Single Article Menu Item, click its Title in Menu Manager: Menu Items.

## Description

Used to show one article in the front end of the site.
