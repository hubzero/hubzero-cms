<a id="overview"></a>

## Overview

This is the edit/creation form for user-submitted feedback.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save**  
  Save changes and return to the edit form.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Select for Notable Quotes page**  
  This indicates if the entry has been selected to be a "notable quote". Notable Quotes can be used by modules to appear in quote lists, be randomly selected for display, etc.
- **Author full name**  
  The author of the feedback. You can open the entry for editing by clicking on the name.
- **Organization**  
  The organization of the author.
- **User ID**  
  The ID of the author, if they have an account.
- **Author consents**  
  - **Author consent to publish quote**  
    An indicator that the author gave permission to make the quote publicly viewable.
  - **Author consent to be contacted for further info regarding this quote**  
    An indicator that the author gave permission to be contacted for future quotes, interviews, etc.
- **Short Quote**  
  This is a currated, trimmed version of the feedback. Typically, this will be one or two lines selected from the body of the full quote.
- **Mini Quote**  
  Like the Short Quote, this is a currated, trimmed version fo the feedback. However, this is meant to be a short, one line/sentence.
- **Full Quote**  
  The submitted feedback.
- **Quote Submitted**  
  The date the feedback was submitted.
- **Editor notes**  
  Any notes concerning the author or feedback an editor may wish to make. This information is displayed to **administrators only**.

<a id="picture"></a>

## Picture

This is an area for any pictures, such as author photo, associated with this quote.
