<a id="description"></a>

## Description

This is where you can add a new Section or edit an existing Section.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="company"></a>

## Company

This is for specifying details about the employing company.

- **Name**  
  The name of the company.
- **URL**  
  The URL to the company's site (if exists).
- **Location**  
  Company location. This is typically City name, State and/or Country.

<a id="job"></a>

## Job

- **Category**  
  The category the job can be found in. The categories can be managed by clicking "Categories" from the sub-menu of the Jobs Manager.
- **Type**  
  The type of position. This is usually something like Full-Time, Part-Time, Freelance, or other common descriptor. The types can be managed by clicking "Types" from the sub-menu of the Jobs Manager.
- **Country**  
  The country the job is in.
- **Title**  
  The job position title.
- **Description**  
  A description for the job. This should enclude information about the details of the job, such as daily duties, qualifications needed, etc.
- **Position Start Date**  
  When the job starts.
- **Applications Due**  
  A due date for all applications to be in by.
- **External URL**  
  An externam URL, possibly with further details or a submission form, related to the position.
- **Allow internal application**  
  Allow site administrators and employees to apply for this position?

<a id="contact"></a>

## Contact Information

This is optional contact information pertaining to the job.

- **Name**  
  The name of whom to contact.
- **Email**  
  The email address of whom to contact.
- **Phone**  
  A phone number the person can be reached at.

<a id="manage"></a>

## Manage This Job

These are administrative controls for changing status and/or messaging the entry creator.

- **Change Status / Take Action**  
  An action to perform.
- **Message to Author**  
  A message to send to the entry creator.
