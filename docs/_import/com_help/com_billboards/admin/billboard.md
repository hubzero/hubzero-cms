<a id="description"></a>

## Description

This is where you can add a new Billboard or edit an existing Billboard.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Images**  
  Upload and manage images used.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="content"></a>

## Billboard Content

- **Name**  
  The Title for this item. This may or may not display on the page, depending on the parameter values you choose.
- **Collection**  
  The collection the entry can be found in.
- **Collection**  
  The collection the entry can be found in.
- **Order**  
  The order in which the entry will appear in the chosen collection.
- **Header**  
  A display header for the billboard.
- **Background Image**  
  The image used for the background of the billboard.
- **Text**  
  The text displayed in the billboard.

<a id="learn-more"></a>

## Learn More Link

- **Text**  
  The text of the link.
- **Target**  
  The URI for the links.
- **Class**  
  A CSS class to apply to the link.
- **Location**  
  The positioning of the link in the billboard.

<a id="styling"></a>

## Billboard Styling

- **Alias**  
  Board alias.
- **Text Padding**  
  The padding applied to the block of text. This is in CSS short-hand and each number position represents a side of padding, in order: top right bottom left. Accepted values are any number followed by **px**, **%**, or **em**. Example: 12px 4px 16px 20px
- **CSS**  
  Custom CSS to apply to the entry.
