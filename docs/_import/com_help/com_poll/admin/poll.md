<a id="description"></a>

## Description

This is where you can add a new Event or edit an existing Poll.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Preview**  
  Preview what the entry will look like.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Save**  
  Save changes and return to the edit form.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Title**  
  The Title for this item.
- **Alias**  
  This is an optional identifier used priamrily for URLs. When an alias isn't provided, one is generated from the provided title. The text is made lowercase, all punctuation is stripped, and spaces are turned into dashes.
- **Lag**  
  The delay time between consecutive votes. This is how long a user must wait before they can vote again.
- **Published**  
  (Published/Unpublished) The published status of the item.
- **Open**  
  (Open/Closed) This indicates if a poll is still accepting votes or not.

<a id="options"></a>

## Options

This is a list of all the available choices for the poll. Each entry represents another choice.
