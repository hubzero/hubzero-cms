<a id="overview"></a>

## Overview

The edit/creation form for a tool version.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Zone**  
  A unique identifier consisting of letters, numbers, and underscores.
- **Title**  
  A title for the entry.
- **Master**  
  --
- **Type**  
  (Local/Remote) The type of zone it is.
- **State**  
  The published status of the item.

<a id="image"></a>

## Image

This is an image or logo associated with the zone. NEw entries must be saved first before an image can be applied.

<a id="locations"></a>

## Locations

A list of locations with various levels of granularity associated with a zone.
