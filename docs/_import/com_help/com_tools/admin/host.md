# Tools Manager: Edit Host

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)

<a id="overview"></a>

## Overview

The edit/creation form for a tool host.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save**  
  Save changes and return to the edit form.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Name**  
  The title of the entry. A required field.
- **Types**  
  The types used by this host. The list of types can be editied via the Host Types manager.
- **Zone**  
  A zone to be associated with this host
