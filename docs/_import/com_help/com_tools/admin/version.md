# Tools Manager: Edit Tool Version

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)

<a id="overview"></a>

## Overview

The edit/creation form for a tool version.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Command**  
  The invoction command for a tool session.
- **Timeout**  
  The types used by this host. The list of types can be editied via the Host Types manager.
- **Required Host**  
  A host required to run a session.
- **Middleware**  
  Middleware used for a session.
- **Perameters**  
  A list of key=value pairs of various parameters a tool session can use.
