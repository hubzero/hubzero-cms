## Overview

## Column Headers

Click on the column heading to sort the list by that column's value. The list will be sorted in order by that column and a sort icon will show next to the column name. Click a second time to reverse the sort to high-to-low. The sort icon will change to high-to-low.

- **Checkbox**  
  Check this box to select one or more items. To select all items, check the box in the column heading. After one or more boxes are checked, click a toolbar button to take an action on the selected item or items. Many toolbar actions, such as Publish and Unpublish, can work with multiple items. Others, such as Edit, only work on one item at a time. If multiple items are checked and you press Edit, the first item will be opened for editing.
- **Raw Tag**  
  The word or phrase as it was entered in.
- **Tag**  
  The normalized version of the raw tag. Normalization makes all characters lowercose, strips punctuation, and only allows letters and numbers.
- **Admin**  
  Indicates if the tag is an admin tag or not. As the name suggests, admin tags are only viewable on the front-end by admins.
- **# Tagged**  
  The number of items in the system that are associated with the tag.
- **Aliases**  
  The number of aliases a tag has. An alias is an alternate spelling, abbreviation, or synonym for the tag.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Options**  
  Opens the Options window where settings such as default parameters or permissions can be edited.
- **Pierce**  
  Copy items from one tag to another. This will essentially duplicate all associated data on a tag (aliases, items tagged, etc.) onto another tag.
- **Merge**  
  Merge two or more tags. This will take all the associations, aliases, etc. from one or more tags and apply them to another tag.
- **New**  
  Opens the editing screen to create a new tag.
- **Trash**  
  Permanently remove a tag and associated data from the site.
- **Help**  
  Opens this help screen.

<a id="sub-menu"></a>

## Sub-menu Links

At the top left, above the filters, you will see sub-menu options. These are essentially filters for blog posts, filtering by the primary scopes (or types) of blogs. The links are:

- **Tags**  
  Show tags in the system.
- **Relationships**  
  A relationship viewer and mapper for tags.
- **Focus Areas**  
  Set focus areas
- **Plugins**  
  A link to the plugin manager, filtering to display only plugins in the "tags" folder.

<a id="list-filters"></a>

## List Filters

Above the column headers is a search box for filtering results by a keyword or phrase.

Click Clear to clear the Filter field and restore the list to its unfiltered state.

## Page Controls

When the number of items is more than one page, you will see a page control bar as shown below.

- **Display #**  
  Select the number of items to show on one page.
- **Start**  
  Click to go to the first page.
- **Prev**  
  Click to go to the previous page.
- **Page numbers**  
  Click to go to the desired page.
- **Next**  
  Click to go to the next page.
- **End**  
  Click to go to the last page.
