# Tags Manager: Tagged Items: Adding/Editing

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)

<a id="overview"></a>

## Overview

You will be presented with a form to create a tag/item link or "tag an item".

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Save**  
  Save changes and return to the edit form.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **ID**  
  ID if the entry.
- **Item Type**  
  The type of item being tagged. This typically corresponds to a component name (without the 'com\_' prefix), such as 'wishlist', 'blog', etc.
- **Item ID**  
  The ID of the item being tagged.
