## Overview

Here you will find a list of submitted tickets. The view is divided between a list of queries (on the left) with various filters applied to generate specific ticket lists and the results of one of those queries (on the right).

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Options**  
  Opens the Options window where settings such as default parameters or permissions can be edited.
- **New**  
  Opens the editing screen to create a new article.
- **Trash**  
  Permanently remove the selected lists and all associated content (wishes, etc.).
- **Help**  
  Opens this help screen.

<a id="sub-menu"></a>

## Sub-menu Links

At the top left, above the filters, you will see sub-menu options. These are essentially filters for blog posts, filtering by the primary scopes (or types) of blogs. The links are:

- **Categories**  
  List all categories.
- **Queries**  
  Area for managing the "Common" queries that every user sees.
- **Messages**  
  List all canned or common response messages to support tickets.
- **Resolutions**  
  List all available resolutions that a ticket can be assigned when closed.
- **Abuse Reports**  
  Content that has been reported as abusive.
- **Tag/Groups**  
  --
- **Stats**  
  Overview of support ticket stats.
- **ACL**  
  Interface for managing the Access Control List for support tickets.

## Page Controls

When the number of items is more than one page, you will see a page control bar as shown below.

- **Display #**  
  Select the number of items to show on one page.
- **Start**  
  Click to go to the first page.
- **Prev**  
  Click to go to the previous page.
- **Page numbers**  
  Click to go to the desired page.
- **Next**  
  Click to go to the next page.
- **End**  
  Click to go to the last page.
