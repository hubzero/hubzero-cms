# Wiki Manager: Edit Comment

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)

<a id="overview"></a>

## Overview

This is the edit/creation form for a comment posted to a wiki page.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Save**  
  Save changes and return to the edit form.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Anonymous**  
  This is a flag to indicate if the user posted the question anonymously. Entries marked as anonymous will not display the poster's name or link to their profile.
- **Content**  
  The primary body of the post. A required field.
