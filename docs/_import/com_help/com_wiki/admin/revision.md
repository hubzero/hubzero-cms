# Wiki Manager: Edit Page Revision

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)
- [Parameters](#parameters)

<a id="description"></a>

## Description

This is where you can add a new Page Revision or edit an existing Page Revision.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Save**  
  Save changes and return to the edit form.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Edit Summary**  
  Any notes or summary of changes made from the previous revision.
- **Content**  
  The primary body of the post. A required field.

<a id="parameters"></a>

## Parameters

- **Minor edit**  
  An indicator as to if the change was a minor change or not.
- **State**  
  (Approved/Not Approved/Trashed) The permissions status of the page. Revisions that have not been approved will not be seen when viewing the page. Revisions must be approved in order to take effect. Trashed revisions will not show up in the public wiki.
- **Created**  
  A timestamp of when the revision was created.
- **Creator**  
  The user who created the revision.
