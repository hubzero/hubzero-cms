<a id="lockedcategories"></a>

## What does a locked category mean?

When a category is locked, no new threads may be created within that category.

<a id="lockedthreads"></a>

## What does a locked thread mean?

When a thread is locked, no new posts may be created within that thread. Essentially, the thread becomes "Read only".

<a id="stickythreads"></a>

## What is a sticky thread?

When a thread is marked as **sticky**, it will be sorted to the top of the list of all threads within a category. This is done typically to highlight a thread containing important or oft-sought information.
