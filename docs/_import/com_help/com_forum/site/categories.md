# Forum Categories

Forum categories are a simple way to group related threads or discussions together.

---

## Locked Categories

When a category is locked, no new threads may be created within that category. Typically, a locked category will be indicated as such by a padloack icon.

---

## Creating a Category

Note that a category **must** be assigned to a section. If a suitable section does not exist, it can be created.

At the bottom of each section, a "New Category" button can be found.

1. Click the "New Category".
2. Provide a title for the category.
3. (optional) Provide a description. This is typically a short, one or two lines.
4. Click "Save".

After saving, the newly created category will be ready for immediate use (i.e., new threads).

## Editing a Category

1. From the main forum page, find the desired category.
2. Click the edit button, typically a small pencil icon.
3. Make any desired changes.
4. Click "Save".

## Locking a Category

When a category is locked, no new threads may be created within that category.

1. From the main forum page, find the desired category.
2. Click the edit button, typically a small pencil icon.
3. Check the box labeled "Lock Category".
4. Click "Save".

## Deleting a Category

When a category is removed, all content within that category will no longer be available. If it is wished that the threads within are preserved, they must be re-assigned to a new category before the category is deleted.

1. From the main forum page, find the desired category.
2. Click the delete button, typically a small trash can icon.
3. You will be asked to confirm deletion.
4. Click "Yes".
