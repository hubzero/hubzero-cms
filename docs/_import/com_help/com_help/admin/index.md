## Getting Started

The Managers' Guide is a user manual for managing the web content and functionality of a HUB. It progresses step-by-step through various common tasks and familiarizes the manager with the administrative back-end interface. Managers will learn how to accomplish tasks such as managing (add/edit/delete) site members, configuring the hub, and more:

- [Site Managers](https://help.hubzero.org/documentation/240/managers)
