# Help

## Getting Started

The Users' Guide is a user manual for a Hub. It progresses step-by-step through the features of the site and how a user can accomplish various tasks:

- [Hub Users](https://help.hubzero.org/documentation/240/users)

## Creating or Modifying Help Pages for Hub Components

Each component may have its own help pages, maintained independently.

Help pages are stored in a "help" subdirectory of a component, e.g., com_help/site/help/en-GB/sample.phtml. This is a sample help page:

Sample Help

Instead of managing individual help pages directly in HTML, consider using the [documentation facility](https://help.hubzero.org/documentation/)
