Select **Components → Events** from the drop-down menu on the back-end of your installation.

<a id="description"></a>

## Description

The Events Manager is where you can edit existing Events and create new ones. Events are organized into Categories.

<a id="column-headers"></a>

## Column Headers

Click on the column heading to sort the list by that column's value.

- **ID**  
  This is a unique identification number for this item assigned automatically. It is used to identify the item internally, and you cannot change this number. When creating a new item, this field displays 0 until you save the new entry, at which point a new ID is assigned to it.
- **Checkbox**  
  Check this box to select one or more items. To select all items, check the box in the column heading. After one or more boxes are checked, click a toolbar button to take an action on the selected item or items. Many toolbar actions, such as Publish and Unpublish, can work with multiple items. Others, such as Edit, only work on one item at a time. If multiple items are checked and you press Edit, the first item will be opened for editing.
- **Title**  
  The name of the item. For a Menu Item, the Title will display in the Menu. This entry is required. You can open the item for editing by clicking on the Title.
- **State**  
  (Published/Unpublished/Archived/Trashed) The published status of the item.
- **Timesheet**  
  An overview of when an event starts and stops.
- **Access**  
  The viewing level access for this item.
- **Pages**  
  The number of pages associated with an event. An event can have pages only if it accepts registration. You can open the list of pages for an event by clicking on the "# Page(s)" link.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar. The functions are:

- **Publish**  
  Makes the selected events available to visitors to your website.
- **Unpublish**  
  Makes the selected events unavailable to visitors to your website.
- **New**  
  Opens the editing screen to create a new event.
- **Edit**  
  Opens the editing screen for the selected event. If more than one event is selected (where applicable), only the first event will be opened. The editing screen can also be opened by clicking on the Title of the event.
- **Trash**  
  Permanently deletes the selected events.
- **Help**  
  Opens this help screen.

<a id="sub-menu"></a>

## Sub-menu Links

At the top left, above the Filter, you will see the following links:

- **Events**  
  Click this link to view a list of all events.
- **Categories**  
  This link takes you to a list of categories for organizing events.
- **Configuration**  
  Click this link to set or change various options for the component.

<a id="list-filters"></a>

## List Filters

- **Filter by Search**  
  Lets you search event titles.
- **Filter by Category**  
  Lets you show only items for the selected category. The categories can be managed by clicking the "Categories" sub-menu item.
- **Filter by Group**  
  Lets you show only items for the selected group.

## Page Controls

When the number of items is more than one page, you will see a page control bar as shown below.

- **Display #**  
  Select the number of items to show on one page.
- **Start**  
  Click to go to the first page.
- **Prev**  
  Click to go to the previous page.
- **Page numbers**  
  Click to go to the desired page.
- **Next**  
  Click to go to the next page.
- **End**  
  Click to go to the last page.
