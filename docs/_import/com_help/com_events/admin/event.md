<a id="description"></a>

## Description

This is where you can add a new Event or edit an existing Event.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Event

- **Title**  
  The Title for this item.
- **Category**  
  A category the event can be found in.
- **Activity**  
  A long description of the event.

<a id="publishing"></a>

## Publishing

- **Start Date**  
  The date the event will start. Format is YYYY-MM-DD
- **Start Time**  
  The time the event will start. Format is HH:mm
- **End Date**  
  The date the event will end. Format is YYYY-MM-DD
- **End Time**  
  The time the event will end. Format is HH:mm
