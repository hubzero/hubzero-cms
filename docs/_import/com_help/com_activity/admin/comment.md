# Blog Entry: Comment

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)

<a id="overview"></a>

## Overview

This is the edit/creation form for a comment posted to a blog entry.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save**  
  Save changes and return to the edit form.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Anonymous**  
  This is a flag to indicate if the user posted the question anonymously. Entries marked as anonymous will not display the poster's name or link to their profile.
- **Content**  
  The primary body of the post. A required field.

<a id="publishing"></a>

## Publishing

- **State**  
  The pulishing state of a comment. This affects how and when an entry is seen.
  
  - **Unpublished** - Does not display on the site or in search results.
  - **Published** - Viewable by site visitors and discoverable in searches and listings.
  - **Trashed** - Does not display on the site or in search results.
  - **Flagged** - Content was flagged. Entry will be visible but content may be replaced with a message denoting it as being under review.
