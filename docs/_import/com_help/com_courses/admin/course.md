## Overview

This is the form for editing a course or creating a new course.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save**  
  Save changes and return to the edit form.
- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

Every entry consists of a **title**, and **alias**. Preferrebly, all entries should also have a short blurb and longer, detailed description.

- **Group**  
  This is for associating a group with a course. If a value is chosen, the course's overview page will display information about the group ownership and can be found by filterting the course catalog by the chosen group.
- **Title**  
  The full name of the course. A required field.
- **Alias**  
  This is an optional unique identifier used priamrily for URLs. When an alias isn't provided, one is generated from the provided title. The text is made lowercase, all punctuation is stripped, and spaces are turned into dashes.
- **Blurb**  
  This is the text that appears in the course catalog and comprises a short one or two sentences that briefly describe the course.
- **Description**  
  A brief description for the collection.
- **Tags**  
  A comma-separated list of tags. Tags are keywords or phrases associated with the course and allow site visitors to discover entries based on topics or interests.

<a id="publishing"></a>

## Publishing

The following options control various aspects of the published state (when and if an entry is available to users).

- **State**  
  The published status of the entry. Unpublished and trashed jobs will never be run.

<a id="image"></a>

## Image

This area is for uploading a picture to be associated with the course. The image can appear int he course catalog, courses intro page, and course overview. **Note:** An entry must be saved first before a picture can be added.

<a id="managers"></a>

## Managers

Here is where users can be made managers of the course, giving them full edit capabilities.
