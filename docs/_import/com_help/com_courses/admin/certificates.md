# Course Certificate

## Overview

The certificate interface allows for a **PDF** to be uploaded. Once uploaded, a preview will be available where you can place, drag, and resize various elements for items such as the user's name, course name, etc. to be dynamically filled in when a certificate is claimed.

## Placing Elements

After uploading a certificate file, a preview of the file will be presented. Just above the preview is a toolbar consisting of a number of buttons. Each button represents a placeholder for information pertaining to the user claiming said certificate. For example, the placeholder "Name" will inject the current ticket redeemer's name into the spot where "Name" is positioned on the certificate preview. Click a button to add an element to the certificate. Position desired elements and click "save".

## Replacing a Certificate / Deleting a Certificate

To replace an existing certificate or remove it entirely, press the "Delete" button (typically, looks like a trashcan) in the top toolbar. This will **permanenetly** remove any uploaded certificate file and layout information (i.e., placeholders).
