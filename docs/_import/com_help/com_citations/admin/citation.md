<a id="description"></a>

## Description

This is where you can add a new Billboard or edit an existing Billboard.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Type**  
  The Title for this item. This may or may not display on the page, depending on the parameter values you choose.

<a id="citation-for"></a>

## Citation For

This is for establishing associations between content on the hub and a specific citation (i.e., the citation is *for* a piece of content on the hub).

<a id="affiliation"></a>

## Affiliation

Indicates if the entry is from an organization affiliated with the hub.
