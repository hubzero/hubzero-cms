# Citations Manager: Edit Type

- [Overview](#overview)
- [Toolbar](#toolbar)
- [Details](#details)

<a id="description"></a>

## Description

This is where you can add a new Type or edit an existing Type.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Details

- **Alias**  
  The alias of the item. Typically, this is a lower-cased version of the title with spaces and punctuation removed. If none provided, one will be generated from the title.
- **Title**  
  The Title for this item.
- **Description**  
  A brief description of the type and what validates as this type.
- **Fields**  
  The fields this type will use.
