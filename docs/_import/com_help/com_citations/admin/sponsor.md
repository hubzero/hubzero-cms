<a id="description"></a>

## Description

This is where you can add a new sponsoror edit an existing Sponsor.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Cancel**  
  Discard any changes made and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="details"></a>

## Citation Sponsor

- **Name**  
  The Title for this item.
- **Link**  
  A link for the sponsor.
- **Image**  
  An image associated with the sponsor. This is typically a logo.
