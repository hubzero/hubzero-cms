<a id="description"></a>

## Description

This is where a format for diplaying a citaiton can be selected (from a list of pre-determined formats) or created (for a custom format).

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Save & Close**  
  Save changes and return to the listing of entries.
- **Help**  
  Opens this help screen.

<a id="format"></a>

## Format

- **Style**  
  Select a pre-determined style for formatting citations, such as APA or IEEE, or a custom style.
- **String**  
  The is where a custom citation format can be created. The format specified here will *only* be used if **Style>** is set to "custom". When creating a format, one can enter from a list of available placeholders to dynamically build the citation for each entry. For example, when "{AUTHORS}" is entered, the system will replace "{AUTHORS}" with the list of authors entered for the citation entry.
