## Overview

Here you will a list of citation entries.

<a id="column-headers"></a>

## Column Headers

Click on the column heading to sort the list by that column's value. The list will be sorted in order by that column and a sort icon will show next to the column name. Click a second time to reverse the sort to high-to-low. The sort icon will change to high-to-low.

- **Checkbox**  
  Check this box to select one or more items. To select all items, check the box in the column heading. After one or more boxes are checked, click a toolbar button to take an action on the selected item or items. Many toolbar actions, such as Publish and Unpublish, can work with multiple items. Others, such as Edit, only work on one item at a time. If multiple items are checked and you press Edit, the first item will be opened for editing.
- **Type**  
  The type the citation is for.
- **Title/Author(s)**  
  The title and list of authors for the item. You can open the item for editing by clicking on the Title.
- **Year**  
  The year of the item being cited (e.g., publication year).
- **Affiliated**  
  Indicates if the entry is from an organization affiliated with the hub.
- **Funded by**  
  Who funded the work behind the citation.

<a id="toolbar"></a>

## Toolbar

At the top right you will see the toolbar.

The functions are:

- **Options**  
  Opens the Options window where settings such as default parameters or permissions can be edited.
- **New**  
  Opens the editing screen to create a new entry.
- **Edit**  
  Opens the editing screen for the selected entry. If more than one entry is selected (where applicable), only the first entry will be opened. The editing screen can also be opened by clicking on the Name of the entry.
- **Trash**  
  Permanently removes the selected entries and any associated content.
- **Help**  
  Opens this help screen.

<a id="sub-menu"></a>

## Sub-menu Links

At the top left, above the filters, you will see sub-menu options. The links are:

- **Citations**  
  A list of citations.
- **Stats**  
  Basic statistics about the entries.
- **Types**  
  The types of materials that can be cited.
- **Sponsors**  
  Sponsors that can be associated with citations.
- **Format**  
  Specify the format citations should appear in (e.g., APA, IEEE).

<a id="list-filters"></a>

## List Filters

Above the column headers is a search box for filtering results by a keyword or phrase.

A select box is also available for determining the sort order of entries displayed.

## Page Controls

When the number of items is more than one page, you will see a page control bar as shown below.

- **Display #**  
  Select the number of items to show on one page.
- **Start**  
  Click to go to the first page.
- **Prev**  
  Click to go to the previous page.
- **Page numbers**  
  Click to go to the desired page.
- **Next**  
  Click to go to the next page.
- **End**  
  Click to go to the last page.
