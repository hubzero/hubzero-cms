# Breadth

The question is “What can I search for?”. The answer is “anything you have access to contained within the list in Search Categories. To see all content within these categories perform a simple query using the wildcard character “\*” as shown below.

A better of what is currently inside Solr’s index can be viewed on the administrative backend by going to Components >> Search >> Search Index Tab. The number of index items is located next to each type. Clicking on the name of the hub type will perform a search on that type, displaying all items that are within the index of that type.
