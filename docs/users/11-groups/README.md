# Groups

## Overview

Groups are a way to connect people with a common interest. They are also an easy way to share content and conversation, either privately or with the world. Group members can:

- Post content that only other group members are allowed to see.
- Export their content to other web sites, and brand it with their own logo.
- Upload a group logo and use it as the group identity.
- Create events on the group calendar that only group members can attend.
