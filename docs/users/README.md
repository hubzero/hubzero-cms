# Hub users

How to use a hub as a member: your profile and dashboard, the groups and
projects you belong to, the resources, publications, and tools you use or
contribute, and the places where the community talks.

Every hub is configured differently, so some features described here may
be switched off or named differently on yours. Where a page refers to a
menu or tab, it means the one on the hub's site, not the administrator
interface.
